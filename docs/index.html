Flowgrammer · document automation

Prepared starters, not a live import

This site is the short map for the flowgrammer-document-automation repository. The long-form guide stays on Flowgrammer. The working pack is the n8n folder on main.

Read the guide first

n8n document processing workflow is the canonical article. Use it for intent, limits, and how the reviewer handoff is supposed to work.

Current pack

n8n Document Processing Starter v0.1.1 is the only pack in the tree. Open https://github.com/Torontostartupcoach/flowgrammer-document-automation/tree/main/n8n for the two prepared workflow JSON files, labelled-text fixtures, and the offline tests.

Later invoice, Power Automate, QuickBooks, and app-specific folders are reserved names. They are not published here.

What is tested

  • Six stdlib Python tests under n8n/tests (workflow shape, Wait contract, timeout path, manual fixture input, five labelled-text fixtures, idempotent retry).
  • On GitHub-hosted runners only: n8n 2.37.11 server-CLI import of both workflow JSON files against a temporary home and database. Both commands must exit zero. That proves n8n 2.37.11 accepted the JSON. It does not execute the graph, publish or activate a workflow, or call an endpoint. It does not prove the live Wait resume item shape.

Labelled-text fixtures do not measure OCR. The live Wait resume item shape (query / body / binary) stays unproven after a green import. Cloud, Slack Approvals, and Extract From File are also outside this test surface.

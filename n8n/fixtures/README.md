# Fixtures

Fictional labelled-text invoices from the published Flowgrammer Invoice Processing Test Pack.

Buyer: Cedar & Quay Fabrication Ltd. Suppliers, GST/HST numbers, and addresses are fictional.

These files do not measure OCR. They do not prove Extract From File or a vendor document-AI adapter.

The prepared default consumes them as labelled-text JSON:

`{ "raw_text": "<file contents>", "filename": "01-clean-invoice.txt", "mime_type": "text/plain" }`

It does not consume PDF or image binaries.
